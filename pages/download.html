How to install

Pick your device — takes under a minute.

Android

  1. Open this page in Chrome.
  2. Tap Install KampoStay App above.
  3. Confirm Install — the app appears on your home screen.

If the button opens this guide again, use Chrome menu → Install app / Add to Home screen.

iPhone / iPad

  1. Open this site in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen, then Add.

Safari is required for iOS install. The app icon will say KampoStay.

Windows / Mac

  1. Open in Chrome or Edge.
  2. Click Install KampoStay App, or the install icon in the address bar.
  3. Launch KampoStay from your apps list like any desktop app.
